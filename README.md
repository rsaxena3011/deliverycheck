# DeliveryCheck

Video delivery checker for Windows.

## What it is

Automatically checks your video deliverables against technical specs: codecs, resolution, frame rate, audio levels, and more. Catches issues before your client does.

The Windows launcher auto-downloads and verifies its own Python and FFmpeg runtimes on first launch. No manual setup.
